# Photos du site

Déposez vos fichiers **dans ce dossier**, avec exactement ces noms.
Chaque photo trouvée remplace automatiquement son placeholder.
Un fichier manquant ne casse rien : le dégradé reste affiché.

Aucune ligne de code à toucher.

---

## Format attendu

| | |
|---|---|
| Extension | `.jpg` |
| Largeur | **2400 px** pour les héros, 1600 px pour le reste |
| Poids | moins de 400 Ko après compression |
| Outil | [squoosh.app](https://squoosh.app) — qualité 75-80 suffit |

> ### À propos des photos Instagram
> Les images téléchargées depuis Instagram font environ **1080 px de large**.
> Elles seront visiblement floues sur un hero plein écran, qui en réclame 2400.
> Utilisables en dépannage pour une démo ; **pas pour une mise en ligne**.
> Les fichiers sources sont à demander au client — c'est le point bloquant n°2
> du brief (`brief/docs/07-contenus-a-recuperer.md`).
